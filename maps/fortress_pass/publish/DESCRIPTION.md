# 隘口要塞 · Fortress Pass

---

## 中文

**一人一座盆地，一人一个隘口。** 守方在北边，每人一座被护城河围住的盆地，只有一座陆桥通向外面；两座盆地之间隔着一条水道，中间有座小桥可以互相支援。攻方在南边的开阔地上，从各个方向往陆桥冲。

### 地图

| | |
|---|---|
| 守方 | 人数较少的队伍，每人一座盆地 |
| 攻方 | 另一队，沿南边一字排开 |
| 通道 | 每座盆地一座陆桥，两侧是深水，没有别的路 |
| 支援 | 相邻盆地之间的水道上有一座小桥 |
| 水域 | 护城河是深水，走不过去；盆地一侧有浅滩，可以捕鱼、造码头 |
| 资源 | 标准开局资源，盆地后方多一座金矿和石矿，前期不用出门 |

### 怎么玩

- 推荐配合游戏模式 **《堡垒模式》**：2 个真人 + 若干 AI，AI 会一波波攻城。
- 也可以当普通的团队对战图：人少的一方守，人多的一方攻。
- 1 个守方就是一座大盆地加一座陆桥；3 个守方就是三座盆地。
- 所有真人放在同一队，AI 放在另一队。

## English

**A basin and a pass for each defender.** The defenders hold the north, each in a basin ringed by a moat with a single land bridge out. A small bridge over the channel between basins lets neighbours help each other. The attackers start on the open plain to the south and storm the bridges.

### The map

| | |
|---|---|
| Defenders | The smaller team, one basin each |
| Attackers | The other team, spread along the south |
| Ways in | One land bridge per basin, with deep water on both sides and no other way in |
| Support | A small bridge over the channel between neighbouring basins |
| Water | The moat is deep: no wading, but the basin side has a shore for fishing and docks |
| Resources | The standard start, plus an extra gold and stone deposit at the back of each basin |

### How to play

- Made for the **Fortress Mode** game mode: two humans against AIs that send siege waves.
- Also works as a plain team game: the smaller team defends, the larger one attacks.
- One defender gets one big basin with one bridge; three defenders get three basins.
- Put all humans on one team and all AIs on the other.
