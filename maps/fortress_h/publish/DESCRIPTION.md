# H 型要塞 · Fortress H

---

## 中文

**背靠背守住 H 的横梁。** 守方在 H 形地图的横梁上，上下都是深湖，左右各有一个又短又窄的口子；攻方从两条竖边同时压过来。一人守一边，顶不住了就喊队友支援。

### 地图

| | |
|---|---|
| 守方 | 人数较少的队伍，在横梁上一字排开 |
| 攻方 | 另一队，轮流分到左右两条竖边 |
| 通道 | 左右各一个窄口，很窄，几段城墙就能封住 |
| 水域 | 横梁上下是深湖，走不过去；可以捕鱼，也能造船 |
| 资源 | 标准开局资源，横梁两端各多一座金矿和石矿 |
| 圣地 | 3 座：横梁中央一座在守方身后，左右竖边靠陆桥各一座在攻方那边 |

### 怎么玩

- 推荐配合游戏模式 **《堡垒模式》**：2 个真人 + 若干 AI，AI 会一波波攻城。
- 也可以当普通的团队对战图：人少的一方守，人多的一方攻。
- 地图大小选中等或以上，横梁会更宽敞。
- 所有真人放在同一队，AI 放在另一队。

## English

**Hold the crossbar back to back.** The defenders sit on the crossbar of an H, with deep lakes above and below and one short, narrow neck at each end. The attackers come from both uprights at once. Each defender holds one side and calls the other for help when it gets tight.

### The map

| | |
|---|---|
| Defenders | The smaller team, spread along the crossbar |
| Attackers | The other team, shared out between the two uprights |
| Ways in | One narrow neck at each end, narrow enough to close with a few wall sections |
| Water | Deep lakes above and below the crossbar: no wading, but fishing and ships work |
| Resources | The standard start, plus an extra gold and stone deposit at each end of the crossbar |
| Sacred sites | Three: one in the middle of the crossbar behind the defenders, and one on each upright by its bridge, on the attackers' side |

### How to play

- Made for the **Fortress Mode** game mode: two humans against AIs that send siege waves.
- Also works as a plain team game: the smaller team defends, the larger one attacks.
- Medium size or larger gives the crossbar more room.
- Put all humans on one team and all AIs on the other.
