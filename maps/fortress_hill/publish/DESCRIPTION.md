# 山顶要塞 · Fortress Hill

---

## 中文

**大家一起守中央高地。** 守方的出生点聚在地图中央一座平缓的小山上，四周是护城河；每位守方带来一对相邻的陆桥，所以每人都有两个挨得很近的口子要守。攻方散布在地图四周，从各个方向往陆桥冲。

### 地图

| | |
|---|---|
| 守方 | 人数较少的队伍，出生点都在高地中央，1～4 人都行 |
| 攻方 | 另一队，均匀分布在地图四周 |
| 通道 | 每位守方一对相邻的陆桥，按左、右、上、下依次分配 |
| 地势 | 平缓的小山，没有悬崖，镜头不会跳 |
| 水域 | 护城河是深水，走不过去；内侧有浅滩，可以捕鱼、造码头 |
| 资源 | 标准开局资源，高地四角各多一座金矿或石矿 |
| 圣地 | 3 座：小山正中间一座，护城河外左右各一座，要出门去抢 |

### 怎么玩

- 推荐配合游戏模式 **《堡垒模式》**：真人 + 若干 AI，AI 会一波波攻城。
- 也可以当普通的团队对战图：人少的一方守，人多的一方攻。
- 2 人守的话，陆桥在左右两侧，一人守一边、背靠背。
- 所有真人放在同一队，AI 放在另一队。

## English

**Hold the hill together.** The defenders start together on a gentle hill in the middle of the map, ringed by a moat. Each defender brings a pair of land bridges close to each other, so every player has two nearby gaps to hold. The attackers are spread around the edge of the map and storm the bridges from every side.

### The map

| | |
|---|---|
| Defenders | The smaller team, starting together in the middle; one to four players |
| Attackers | The other team, spread evenly around the edge |
| Ways in | A pair of close land bridges per defender, placed left, right, top and bottom in turn |
| Height | A gentle hill with no cliffs, so the camera stays steady |
| Water | The moat is deep: no wading, but the inner side has a shore for fishing and docks |
| Resources | The standard start, plus an extra gold or stone deposit in each corner of the plateau |
| Sacred sites | Three: one in the middle of the hill and one outside the moat on each side, to be fought for |

### How to play

- Made for the **Fortress Mode** game mode: humans against AIs that send siege waves.
- Also works as a plain team game: the smaller team defends, the larger one attacks.
- With two defenders the bridges are on the left and right, so you hold one side each, back to back.
- Put all humans on one team and all AIs on the other.
